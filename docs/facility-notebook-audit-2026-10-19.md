# 施設詳細・サ活ノートの改善と確認範囲

調査日: 2026-10-19（日本時間）。再送された4枚のiPhone画面と、本番・ローカル画面、コード、公式出典を照合した。

## 確認した問題

- 押印済みのときにアクションが増え、2列グリッドに空きマスができていた。
- メモ・サ活ログ・口コミが独立したフォームで、似た感想を繰り返し入力する構造だった。
- 390×844pxの本番施設詳細では、メモ見出し約2,633px、サ活約3,136px、口コミ約3,710pxの位置にあった。
- 住所・掲載状態・使い方案内・広告が入力欄より先に並び、主要操作から記録までが長かった。
- 添付画像で日付欄がセット数の欄に重なっていた。ヘッダーの最終CSSではsafe-area上余白が上書きされていた。
- 既存の設備・タグには項目別の出典がなく、施設名や過去の掲載タグを確定した設備情報として扱うことはできなかった。

## 実装

- 施設情報 / サ活ノート / 口コミをボタンで切り替える構成に変更。記録・口コミへは手動スクロールをせず直接移れる。
- 記録の本文は1欄。通常は非公開の端末内メモとして保存し、セット・時間の記録、口コミ公開は別々に明示選択する。
- 過去のメモ・訪問ログ・口コミは維持。保存済み訪問ログの編集・画像共有・削除、メモの削除も維持した。
- 公開失敗時も端末保存は残す。再送時の訪問ログは同じIDで更新し、重複を防ぐ。保存領域の失敗時はメモリ状態を戻し、公開送信しない。
- 送信中の重複操作、再描画後の二重送信、送信中に変更した下書きの消失を回帰テストに追加した。
- 主要操作は濃い緑、補助操作は落ち着いた輪郭線を基本とする。押印取消・共有・周辺情報は開閉領域へ整理した。
- 大きなコレクション画像は開閉式にし、料金・時間・利用条件を先に読めるようにした。重複する住所・説明パネルは統合した。
- 日付は単独行、数値欄は可変幅2列。最小幅0・最大幅100%を指定し、safe-area上余白の上書きを修正した。
- 公式出典30項目を6施設に追加。検索カードにも主要3項目を表示し、詳細・静的HTMLも同じ出典データを使用する。
- 旧設備タグは「未再照合」として分離。裏付けのないタグを確定表示・構造化データ・設備フィルターへ流用しない。ユーザー登録設備は公式照合済みとは区別する。

## 実画面検証

ブラウザの画面サイズ変更による検査であり、iPhone実機・キーボード・VoiceOverの検査ではない。

- 320×740 / 390×844 / 430×932 / 1440×900で施設詳細の横はみ出しなし。
- SAUNA MONKEYの通常メモは「サ活を書く」1タップ後、追加スクロール0で本文・保存ボタンを表示。数値記録を展開した場合や短い高さの画面、長い施設名も全てスクロール不要という意味ではない。
- 320px幅の展開済み日付欄は横幅281pxで親欄内に収まり、隣の数値欄との交差なし。
- 430px幅の口コミパネルは上端約264px、main.scrollTop=0で表示。
- ローカルKVで口コミの投稿・表示・本人削除を実行し、テスト投稿は削除済み。本番へのテスト投稿はしていない。
- 入力中の下書き、非公開保存、連続保存の重複防止をローカルUIで確認した。

証跡は `output/playwright/detail-audit-2026-10-19/` に保存（Git管理対象外）。改善前 `01-before-detail.png`、改善後 `final-note-390.png`、`final-note-1440.png`、`final-reviews-430.png`、矩形情報 `layout-metrics.json`。

## 未達・残る課題

`npm run audit` は成功していない。全体のカタログ確認日を実態なく書き換えず、エラーを維持している。

```text
"ok": false
"catalogReviewedAt": "2026-07-11"
"facilitiesRaw": 5000
"officialProfilesWithFieldEvidence": 6
"officialFactsWithSources": 30
"withAddress": 1101
"withOfficialUrl": 632
"withNote": 210
"sourcesCheckedInLast60Days": 1190
"addressesCheckedInLast60Days": 748
"errors": ["カタログ確認日から60日を超えています: 2026-07-11"]
```

上記の元データ件数は別名統合前であり、6施設の補足情報とは別集計。参照ページの取得日と、営業・設備の項目別確認日は異なる。

したがって、全4,974施設の情報が2026年10月19日現在で最新・正確であるとは認定できない。残る施設の公式照合、実機iPhoneのsafe-area・キーボード、利用者の誤操作率・所要時間は未確認。静的SEO検査の成功も検索順位やAI回答への掲載を保証するものではない。
