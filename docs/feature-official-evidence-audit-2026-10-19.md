# 特徴検索・周辺サ飯・公式掲載情報の監査（2026-10-19）

## 結論と未完了事項

特徴検索と周辺サ飯の不具合を修正した。公式の項目付き情報は18プロフィール・97項目から134プロフィール・325項目に増加した。
今回追加した内訳は、運営者・自治体サイトからの構造化抽出114施設・220項目と、個別確認2施設・8項目。
ただし、全国の大半の料金・設備・温度を更新した状態ではない。全5,000生データのうち料金等の公式項目を1つ以上持つのは138件（2.76%、別名を含む）。
料金20プロフィール、浴場等の営業時間18プロフィール、サウナ設備・温度9プロフィール。抽出分の主力は施設営業時間106件と休館日99件であり、浴場の利用可能時間とは区別する。
七カテゴリの項目が揃うのは生データ8件（別名込み）。カテゴリ内の全設備・全温度まで網羅したことは意味しない。
95点以上、全施設の最新性、Google Mapsの距離・営業情報の正確さは保証していない。

## 1. 特徴検索

問題:

- 全特徴が件数に関係なく選択可能だった。
- おかざき楽の湯の公式本文にある塩サウナ・遠赤外線サウナが検索用の確認済みタグに不足していた。
- オートロウリュは公式データにあっても特徴の選択肢に存在せず、正規化で落ちていた。

修正:

- 現在の都道府県・文字検索・保存状態・他の選択特徴を反映して件数を表示する。
- 未選択で0件の項目は別の開閉領域にまとめ、無効にする。設備の不存在とは扱わない。
- 県変更等で選択済みが0件になった場合も、当該ボタンと一括解除を操作可能に保つ。
- 複数選択はAND。外気あり/なし等の排他的条件では切替後の件数を表示する。
- 塩サウナは全国2件（おかざき楽の湯・りっかりっか湯）を実画面で確認。
- 公式に同一と確認したID群で検索結果と静的ページの別名を統合。保存済みIDを優先する既存動作は維持する。
- 共有文も旧タグではなく確認済み・ユーザー登録の特徴を使用する。

公式出典:

- https://rakunoyu.com/okazaki/sauna.html
- https://www.nahacen.com/rikka/index.html
- https://kameyama-sauna.com/
- https://leopards.co.jp/service/aounomori

## 2. 周辺サ飯

修正前は施設名・エリアだけをGoogle Mapsの検索語に渡していた。アプリ内に距離検証済みの飲食店リストは存在しない。
座標を自然文に入れる案も検証したが、那覇の座標を指定しても別地域の結果になるケースがあったため採用しなかった。

採用した検索語は `飲食店 <掲載住所> 周辺`。住所未掲載の場合のみ施設名・エリアを使う。
りっかりっか湯の住所指定で、那覇うまい処九年母亭・お食事処ゆんたく等、牧志周辺の結果を確認した。
Google Maps側の順位・距離・営業中判定は制御できないため、アプリ上でも検索先での確認を明記する。
Google Maps公式仕様: https://developers.google.com/maps/documentation/urls/get-started

## 3. 公式ページの調査・採用基準

`npm run audit:official-sources` で既存の公式リンク649候補へ取得を試行した。HTML取得成功492件、失敗157件。
失敗内訳: robots未取得/不許可82、404が63、リダイレクト上限4、500が2、400が1、403が3、406が1、タイムアウト1。
制限を回避する再試行はしていない。並列数4、同一ホストの間隔は最低1秒（Crawl-delayが長ければその値）とした。

採用条件:

- 運営者または自治体の施設サイトとして採用対象にしたホストであること。
- title/h1と施設名が一致すること。
- dt/ddまたはth/tdで項目名と値を対応づけられること。
- 料金の年齢等の区分を維持すること。列見出しの解釈が不明な料金表は採用しない。
- テーブル全体の医療的効能・別料金・他テナントの項目を料金へ混ぜない。
- 異なる営業時間が複数あれば、施設と飲食店等を自動判別せず保留する。
- 0名・「なし」等から肯定の設備タグを生成しない。
- 個別に確認済みのプロフィールを機械抽出で上書きしない。

`npm run compile:official-evidence` は取得済みのローカル監査レポートからデータを生成する。生成内容は出典と取得日を持ち、ブラウザと静的SEOページで共用する。
構造化抽出の日付は「公式ページ掲載値の取得日」であり、営業中であることや全項目を人手で確認した日ではない。
今回の採用対象外のページや、公式リンクのない施設については補完が残る。

個別確認では、FIRST THE SAUNAの公式2026年9月25日告知が再開未定の臨時休業を案内していたため、通常の案内ページより優先した。
休業表示・押印制限に加え、近隣推薦・滞在チェックインからも除外する。
https://first-kyoto.com/news/316/

- 単体テスト38件: 特徴件数、排他的切替、0件解除、公式タグ、別名保存ID、周辺検索語、休業時の推薦・チェックイン、抽出誤認、既存の記録・口コミ・ランキング。

- 特徴パネル開閉の両状態で測定。80msの入力待ちを含む。実機の表示完了時間・INPではない。
